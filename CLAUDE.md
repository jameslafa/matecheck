# Claude Code Instructions for MateCheck

This file contains project-specific instructions for Claude Code when working on the MateCheck project.

## Git Workflow

**Never commit automatically.** Always wait for explicit user approval before running any git commit commands.

**Always test changes before committing.** Run the build, linter, or test suite to verify changes work before proposing a commit.

**Do not add Co-Authored-By tags to commits** unless explicitly asked.

## General Principles

**Keep things simple and minimal.** Do not over-engineer solutions, add unnecessary demo content, verbose documentation, or lengthy commit messages. Start with the simplest approach that works.

**When a first approach fails or produces errors, stop and reassess the strategy** rather than continuing down the same path. If something has failed twice, propose an alternative approach to the user.

## CSS & Styling

**When making CSS/styling changes, make one small change at a time** and confirm the result before moving on. Do not attempt large-scale layout refactors in a single edit.
